# Homebrew Tap for NotchDock

Official Homebrew Cask tap for [NotchDock](https://notchdock.app) — a native macOS Dynamic Island productivity HUD and Apple Notes scratchpad in pure Swift 6.

## Installation

```bash
brew tap rohanrony/notchdock
brew install --cask notchdock
```

## Update

```bash
brew upgrade --cask notchdock
```

## Uninstallation

```bash
brew uninstall --cask notchdock
```
